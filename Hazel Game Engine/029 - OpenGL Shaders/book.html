2. 什么是 Shader

(参考时间: 00:06:49)

Shader 是运行在 GPU 上的程序，用来决定 GPU 如何处理传入的数据。

两种最常见的 Shader：

Shader 执行次数 主要职责
Vertex Shader 每个顶点一次 计算顶点在裁剪空间中的位置
Fragment / Pixel Shader 每个片元或像素一次 计算该像素最终颜色

OpenGL 把它称为 Fragment Shader；DirectX 等 API 常称为 Pixel Shader。

对于上一讲的三角形：

3 个顶点
  -> Vertex Shader 执行 3 次
  -> 光栅化产生大量片段
  -> Fragment Shader 为每个片段决定颜色

graph LR
    A[3 个顶点] --> B[Vertex Shader x3]
    B --> C[三角形光栅化]
    C --> D[大量 Fragment]
    D --> E[Fragment Shader]
    E --> F[颜色]

3. 图形管线中的数据流

(参考时间: 00:09:35)

顶点 Shader 的主要输出是裁剪空间位置：

gl_Position = ...;

裁剪空间坐标通常在：

x: -1 到 +1
y: -1 到 +1
z: -1 到 +1

顶点位置经过图元装配和光栅化后，被转换为覆盖三角形区域的片段。

片元 Shader 再决定每个片段的颜色：

out vec4 color;
color = vec4(1.0, 0.0, 0.0, 1.0);

flowchart TD
    A[Vertex Buffer] --> B[Vertex Shader]
    B --> C[Clip Space Position]
    C --> D[Primitive Assembly]
    D --> E[Rasterization]
    E --> F[Fragment Shader]
    F --> G[Framebuffer Color]

4. Shader 编译与链接

(参考时间: 00:12:39)

GLSL 是 OpenGL Shading Language。Shader 虽然运行在 GPU，但创建过程与 CPU 程序类似：

  1. 创建 Shader 对象；
  2. 提交源码；
  3. 编译 Shader；
  4. 检查编译状态；
  5. 读取错误日志；
  6. 创建 Program；
  7. 附加顶点与片元 Shader；
  8. 链接 Program；
  9. 检查链接状态；
  10. 分离并删除临时 Shader。
flowchart TD
    A[glCreateShader Vertex] --> B[glShaderSource]
    B --> C[glCompileShader]
    C --> D{编译成功?}
    D -- 否 --> E[读取 InfoLog]
    D -- 是 --> F[创建 Fragment Shader]
    F --> G[编译 Fragment]
    G --> H[glCreateProgram]
    H --> I[Attach + Link]
    I --> J{链接成功?}
    J -- 否 --> K[读取 Program InfoLog]
    J -- 是 --> L[Detach / Delete Shader]

5. 编译顶点 Shader

(参考时间: 00:15:20)

创建顶点 Shader：

GLuint vertexShader =
    glCreateShader(GL_VERTEX_SHADER);

const GLchar* source = vertexSrc.c_str();

glShaderSource(
    vertexShader,
    1,
    &source,
    0);

glCompileShader(vertexShader);

检查编译结果：

GLint isCompiled = 0;
glGetShaderiv(
    vertexShader,
    GL_COMPILE_STATUS,
    &isCompiled);

如果失败：

GLint maxLength = 0;
glGetShaderiv(
    vertexShader,
    GL_INFO_LOG_LENGTH,
    &maxLength);

std::vector<GLchar> infoLog(maxLength);
glGetShaderInfoLog(
    vertexShader,
    maxLength,
    &maxLength,
    infoLog.data());

glDeleteShader(vertexShader);

HZ_CORE_ERROR("{0}", infoLog.data());
HZ_CORE_ASSERT(
    false,
    "Vertex shader compilation failure!");

6. 编译片元 Shader

片元 Shader 使用相同的编译流程，只是类型改为：

GLuint fragmentShader =
    glCreateShader(GL_FRAGMENT_SHADER);

如果片元 Shader 编译失败，需要同时删除：

glDeleteShader(fragmentShader);
glDeleteShader(vertexShader);

因为顶点 Shader 已经成功创建，但整个 Shader Program 无法继续构建，必须避免资源泄漏。

flowchart TD
    A[Vertex Shader] --> B{编译成功?}
    B -- 否 --> C[删除 Vertex 并报错]
    B -- 是 --> D[Fragment Shader]
    D --> E{编译成功?}
    E -- 否 --> F[删除 Fragment 与 Vertex]
    E -- 是 --> G[链接 Program]

7. 链接 Shader Program

(参考时间: 00:22:20)

创建程序对象：

m_RendererID = glCreateProgram();
GLuint program = m_RendererID;

附加并链接：

glAttachShader(program, vertexShader);
glAttachShader(program, fragmentShader);
glLinkProgram(program);

检查链接状态：

GLint isLinked = 0;
glGetProgramiv(
    program,
    GL_LINK_STATUS,
    &isLinked);

失败时：

glDeleteProgram(program);
glDeleteShader(vertexShader);
glDeleteShader(fragmentShader);

HZ_CORE_ERROR("{0}", infoLog.data());
HZ_CORE_ASSERT(
    false,
    "Shader link failure!");

成功时：

glDetachShader(program, vertexShader);
glDetachShader(program, fragmentShader);

链接完成后，Shader Program 已经持有编译结果，可以分离并删除独立的 Shader 对象。

sequenceDiagram
    participant C as Shader class
    participant GL as OpenGL

    C->>GL: glCreateProgram
    C->>GL: Attach vertex/fragment
    C->>GL: glLinkProgram
    GL-->>C: Link status
    C->>GL: Detach shaders
    C-->>C: keep program ID

8. Shader 类接口

(参考时间: 00:24:00)

新增：

Hazel/src/Hazel/Renderer/Shader.h
Hazel/src/Hazel/Renderer/Shader.cpp

#pragma once

#include <string>

namespace Hazel {

class Shader
{
public:
    Shader(
        const std::string& vertexSrc,
        const std::string& fragmentSrc);
    ~Shader();

    void Bind() const;
    void Unbind() const;

private:
    uint32_t m_RendererID;
};

}

m_RendererID 保存 OpenGL Shader Program 的句柄。

绑定和解除绑定：

void Shader::Bind() const
{
    glUseProgram(m_RendererID);
}

void Shader::Unbind() const
{
    glUseProgram(0);
}

析构时删除 Program：

Shader::~Shader()
{
    glDeleteProgram(m_RendererID);
}

        -uint32_t m_RendererID
        +Shader(vertexSrc, fragmentSrc)
        +Bind()
        +Unbind()
        +~Shader()
    }

10. 使用 Raw String 编写 GLSL

(参考时间: 00:29:35)

普通 C++ 字符串需要逐行拼接和转义：

std::string src =
    "#version 330 core\n"
    "layout(location = 0) in vec3 a_Position;\n";

不方便直接粘贴多行 Shader。

C++11 Raw String 可以保留原始换行：

std::string vertexSrc = R"(
    #version 330 core

    layout(location = 0) in vec3 a_Position;

    void main()
    {
        gl_Position = vec4(a_Position, 1.0);
    }
)";

    A[普通字符串] --> B[每行引号 + \\n]
    C[Raw String] --> D[保留多行与缩进]

11. 编写顶点与片元 Shader

顶点 Shader：

#version 330 core

layout(location = 0) in vec3 a_Position;

void main()
{
    gl_Position = vec4(a_Position, 1.0);
}

片元 Shader：

#version 330 core

layout(location = 0) out vec4 color;

void main()
{
    color = vec4(1.0, 0.0, 0.0, 1.0);
}

命名约定：

  • a_ 表示输入 Attribute；
  • v_ 表示在 Shader 之间传递的 Varying 变量；
  • gl_Position 是顶点 Shader 的内建裁剪空间输出；
  • 颜色使用 RGBA 四分量向量。
graph LR
    A[a_Position] --> B[Vertex Shader]
    B --> C[gl_Position]
    B --> D[v_Position]
    D --> E[Fragment Shader]
    E --> F[color]

14. Shader 之间的数据传递

(参考时间: 00:36:00)

顶点 Shader 可以输出可变变量：

out vec3 v_Position;

void main()

15. 为什么会出现黑色区域

(参考时间: 00:37:27)

顶点位置范围是：

-1 到 +1

颜色通道通常被限制在：

0 到 1

如果把负坐标直接作为颜色：

color = vec4(v_Position, 1.0);

负值会被截断为 0，表现为黑色。

转换到 0..1：

color = vec4(
    v_Position * 0.5 + 0.5,
    1.0);

映射关系：

-1.0 -> 0.0
 0.0 -> 0.5
+1.0 -> 1.0

flowchart LR
    A[-1.0] --> B[0.0]
    C[0.0] --> D[0.5]
    E[+1.0] --> F[1.0]

16. 颜色插值与坐标轴

(参考时间: 00:38:11)

顶点之间会进行线性插值：

左顶点: 负值
中 间: 接近 0
右顶点: 正值

所以最终颜色会在三角形内部平滑变化。

坐标轴与 RGB 对应：

坐标 颜色通道
x red
y green
z blue

移动三角形或增加偏移后，可以看到红色与绿色分布变化。

graph TD

    C[Y 轴] --> D[Green]
    E[Z 轴] --> F[Blue]
    B --> G[Fragment 插值]

17. Shader 生命周期与资源管理

当前 Shader 类已经处理：

  • 顶点编译失败时删除顶点 Shader；
  • 片元编译失败时删除两个 Shader；
  • 链接失败时删除 Program 和两个 Shader；
  • 链接成功后分离 Shader；
  • 析构时删除 Program。
flowchart TD
    A[Vertex compile] --> B{Fail?}
    B -- 是 --> C[Delete vertex]
    B -- 否 --> D[Fragment compile]
    D --> E{Fail?}
    E -- 是 --> F[Delete fragment + vertex]
    E -- 否 --> G{Link}
    G -- Fail --> H[Delete program + both shaders]
    G -- Pass --> I[Detach + keep program]
    I --> J[Destructor deletes program]
